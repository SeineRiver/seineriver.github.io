# Image Gallery

A standalone, browser-only image gallery for the images stored in [`images/`](./images/).

## Use

Open [`index.html`](./index.html) in a browser, or visit `/gallery/` on the published site. The gallery loads the bundled images automatically. You can also select another local image folder with **Choose folder…**.

## Contents

```text
index.html    Gallery markup, styling, and client-side logic
images/       Bundled gallery images
```
